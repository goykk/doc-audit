# P9 复核队列分页验收

## 目标

44 条 pending 不应一屏堆到底；分页后每页 15 条，选择范围明确。

## 实现

- `queueState.page / pageSize=15`
- 筛选（规则/搜索）后重新分页，并重置到第 1 页
- “全选本页”只选中当前页，不是全部筛选结果
- 底部增加“上一页 / 页码 / 下一页”
- 跨页选择保留；已选数量按全部选中项统计
- 筛选后页数不足时自动钳制页码

## 浏览器验证

```
page1 rows 15, page 1/3
page2 rows 15, page 2/3
全选本页 -> 已选 15 项
console errors 0
```

44 条 pending，筛选后 44 条，3 页。截图：`reports/ui_p9_queue_pagination.png`。

## 测试

68 个测试通过；容器 healthy，页面 200。

## 边界

- 当前是前端分页，队列接口仍一次拉取最多 200 条；
- 未做服务端筛选/分页，超过 200 条需要下一步补；
- 分页与批量驳回独立：批量只处理已勾选项，不自动全选所有页。
