## 结论

1. **三种模式都没有出现格式错误**：10/10 严格 JSON 合法、0 次修复。qwen3-vl-plus 在明确要求 JSON 的 prompt 下已经足够稳定，服务端约束没有带来格式收益。
2. **严格 Schema 没有提升字段 F1**：0.8243，低于自由文本/JSON Object 的 0.8276；幻觉率反而从 0.1795 升到 0.2099。
3. **Schema 的代价明确**：单文档输入 token 从 1423 增到 2246，单文档成本从 ¥0.0064 增到 ¥0.0074。
4. 这个负结论有边界：它只说明**强多模态模型 + 明确 JSON prompt** 下 Schema 约束收益不足，不能推广到弱模型、自由文本生成或需要工具调用契约的场景；生产默认仍保留 JSON Object 模式作为低成本保险。
